# ContextMenu

The right-click menu on a data product name in the All Data Product Table.

## Rules
- `surface`, `border`, `radius-lg`, `shadow-menu`, 208px wide; the product name heads the menu in `body-small` `ink-muted`.
- Items in `body-medium` with a 16px icon. Destructive items use `danger-action` text and `danger-soft` hover.
- Each item opens a Modal; nothing is changed from the menu itself.
- The name cell shows the tooltip "Right-click to rename or delete".
