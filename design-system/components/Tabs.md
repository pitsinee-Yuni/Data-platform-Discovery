# Tabs

The five tabs of a data product page, always in this order: Overview, Data Dictionary, Preview, Quality Report, Lineage.

## Rules
- `body-medium` text at 500; inactive `ink-muted`, hover `ink` with a `border-control` underline; active `primary` with a 3px `primary` underline.
- Tabs keep the selected source between them (except Quality Report, which has no All).
