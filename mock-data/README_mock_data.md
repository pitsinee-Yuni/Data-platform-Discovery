# ข้อมูลจำลองสำหรับทดสอบ Discovery

ข้อมูลทั้งหมดเป็น**ข้อมูลสมมติ** ชื่อคน เบอร์โทร (081-000-xxxx) และรหัสคำขอสร้างขึ้นใหม่ทั้งหมด ไม่มีข้อมูลจริงของประชาชนหรือหน่วยงาน

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `discovery_mock_service_requests_1000.csv` | ข้อมูลคำขอรับบริการ 1,000 แถว วันที่ 16 ก.ย. – 15 ต.ค. 2026 (30 วัน วันละ 33–34 แถว) UTF-8 เปิดใน Excel ภาษาไทยได้ |
| `data_dictionary_design.csv` | แบบ (Data Dictionary) ที่ใช้กรอกในระบบก่อนนำเข้า พร้อมระบุคอลัมน์ที่บังคับกรอก |

## คอลัมน์

| คอลัมน์ | บังคับกรอก | หมายเหตุ |
|---|---|---|
| request_id | ใช่ | REQ-YYMMDD-NNNN |
| source_system | ใช่ | 3 แหล่ง: `eservice_portal` (397 แถว), `counter_system` (358), `legacy_regional` (245) แยกเป็น 3 ไฟล์ตามแหล่งได้ |
| request_date | ใช่ | รูปแบบมาตรฐาน YYYY-MM-DD |
| applicant_name | ใช่ | ชื่อสมมติ |
| province | ใช่ | ชื่อจังหวัดมาตรฐานภาษาไทย 6 จังหวัด |
| service_type | ใช่ | 5 ประเภทบริการ |
| fee_amount | ใช่ | ตัวเลขทศนิยม 2 ตำแหน่ง |
| payment_status | ใช่ | ชำระแล้ว / รอชำระ / ยกเลิก |
| contact_phone | ไม่ | ว่างประมาณครึ่งหนึ่ง (ว่างได้ ไม่ผิด) |
| remark | ไม่ | ว่างเกือบทั้งหมด |
| legacy_ref | – | **ไม่มีในแบบ** มีเฉพาะแถวของ legacy_regional |

## สิ่งที่ตั้งใจใส่ไว้ให้ทดสอบ

1. **แหล่งสกปรกแหล่งเดียว:** ข้อมูลผิดอยู่ใน `legacy_regional` เท่านั้น (52 แถว จาก 245) อีก 2 แหล่งสะอาดทั้งหมด → ทดสอบตัวกรอง Source (US-11)
2. **วันที่คุณภาพตก:** 1–7 ต.ค. 2026 แหล่ง legacy_regional ผิด 40 จาก 61 แถว ก่อนและหลังช่วงนี้ผิดน้อย → กราฟ Data Quality Trend ต้องเห็นตกแล้วกลับขึ้น (US-09)
3. **ค่าที่แปลงได้ (Pass หลังแปลง):** วันที่ปี พ.ศ. (07/10/2569) ตัวเลขไทย (๐๗/๑๐/๒๕๖๙) 02-Oct-2026, 2026/10/03 · ยอดเงิน ฿1,200, 1,200.00, 800 บาท · จังหวัด กทม., กรุงเทพฯ, Bangkok, ชม., Songkhla · สถานะ paid, จ่ายแล้ว, cancel
4. **ค่าที่แปลงไม่ได้ (Chain Exhausted):** วันที่ "พรุ่งนี้" และยอดเงิน "หนึ่งพันบาท" รวม 8 ช่อง และค่า "-" ในยอดเงิน
5. **ช่องว่างในคอลัมน์บังคับ (Missing):** applicant_name (1), province (3), fee_amount (3) รวม 7 ช่อง
6. **Completeness ต่ำกว่า Pass:** contact_phone และ remark ว่างเยอะ (ว่างได้) จึงนับเป็น Pass แต่ดึง Completeness ทั้งชุดลงเหลือประมาณ 80%
7. **ตรวจโครงสร้างเทียบแบบ (US-05):** แบบมีคอลัมน์ `channel` แต่ข้อมูลไม่มี → ต้องขึ้น **Missing** · ข้อมูลมี `legacy_ref` แต่แบบไม่มี → ต้องขึ้น **Not in design** · `fee_amount` ในแบบเป็น DECIMAL แต่ CSV อ่านได้เป็นข้อความ → อาจขึ้น **Found as VARCHAR**

## ผลที่ควรเห็นในระบบ

- `eservice_portal` และ `counter_system`: Pass ใกล้ 100% E-Score สีเขียว
- `legacy_regional`: Pass ต่ำกว่าแหล่งอื่นชัดเจน และ Investigate Rows ต้องเห็นค่าตัวอย่างข้างบน
- ภาพรวมทั้งชุด: Completeness ประมาณ 80% (สีส้ม เพราะต่ำกว่า 90%) แม้ Pass จะสูงกว่า
